
# PRODUCT_VALUES.md

# Investment Terminal — Product Values

**Status:** Canonical Product Values

---

# 1. Purpose

This document defines the values that guide product decisions whenever trade-offs
must be made. Features may change over time; these values should remain stable.

---

# 2. Trust Over Features

User trust is more valuable than adding another capability.

If a feature reduces transparency or predictability, it should be redesigned.

---

# 3. Explainability Over Complexity

Every important recommendation should be understandable.

The system must explain why it reached a conclusion.

---

# 4. Data Quality Over Data Quantity

Prefer fewer, high-quality inputs over many unreliable ones.

Missing data should be reported rather than guessed.

---

# 5. Evidence Before Opinion

Facts come first.

Interpretation is built on validated evidence.

AI explanations should always distinguish between evidence and interpretation.

---

# 6. History Is an Asset

Historical information is part of the product.

Snapshots are immutable.

Knowledge grows from accumulated history rather than memory.

---

# 7. Human Remains Responsible

Investment Terminal supports decisions.

It does not replace the investor.

Recommendations are not instructions.

---

# 8. Long-Term Thinking

Design for years, not releases.

Architectural consistency is preferred over short-term convenience.

---

# 9. Transparency

Be honest about:

- missing information;
- assumptions;
- limitations;
- uncertainty.

Confidence reflects evidence quality, not probability of future returns.

---

# 10. Consistency

Equivalent inputs should produce equivalent outputs.

Stable behaviour builds confidence in the product.

---

# 11. Simplicity

Prefer simple designs that are easy to explain.

Avoid unnecessary abstraction.

---

# 12. Continuous Improvement

Each completed review should improve the overall value of the platform by
expanding structured historical evidence.

---

# 13. Respect for User Data

Portfolio information belongs to the user.

The product should minimize unnecessary exposure of personal financial data.

---

# 14. Sustainable Engineering

Engineering choices should reduce long-term maintenance cost.

Technical debt should be explicit and actively managed.

---

# 15. Product Identity

Investment Terminal is:

- not a prediction engine;
- not an automated trading system;
- not a promise of investment returns.

It is a deterministic investment intelligence platform.

---

# 16. Decision Framework

When values conflict, prefer:

1. Trust
2. Correctness
3. Explainability
4. Historical integrity
5. Maintainability
6. Performance
7. Feature completeness

---

# 17. Guiding Statements

> Preserve evidence.

> Reduce uncertainty.

> Explain conclusions.

> Keep history immutable.

> Build confidence through transparency.

> Help people make better informed investment decisions.

> Every completed review should make the next decision better informed than the previous one.
